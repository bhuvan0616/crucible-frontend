## Existing Status Color Pattern

## OrderTimeline Data Structure

The order object from Medusa SDK (`sdk.store.order.retrieve` with `fields: "*"`) includes a `fulfillment_status` field and timestamps. For a proper timeline, we need to extract fulfillment events from the order. The typical Medusa order has:
- `created_at` — Order placed
- `payment_authorized_at` — Payment confirmed (if applicable)
- `fulfillment_status` — Current fulfillment state
- `items` — Line items with fulfillment information

Since the order data structure from Medusa includes timestamps for various events, the OrderTimeline will derive stages from available order metadata. The timeline stages are:
1. Order Placed (created_at)
2. Payment Confirmed (payment_authorized_at if available)
3. Items Prepared (first fulfillments created_at)
4. Shipped (fulfillment shipments tracking)
5. Delivered (final fulfillment status)

If Medusa returns fulfillment data with status history, we'll use that. Otherwise, the timeline will show available stages based on current fulfillment status.
