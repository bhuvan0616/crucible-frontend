## Spacing Scale

8-point grid, all values multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, tight gaps |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, component gaps |
| xl | 32px | Layout gaps, section internal spacing |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical spacing |

**Exceptions:** None for Phase 1.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0F172A` | Page background, dark surfaces |
| Secondary (30%) | `#1E293B` | Cards, elevated surfaces, nav background |
| Accent (10%) | `#14B8A6` | Highlights, borders, interactive states |
| CTA | `#F97316` | Primary action buttons only |
| Destructive | `#EF4444` | Destructive actions only |
| Neutral Mid | `#64748B` | Muted text, secondary labels |
| Neutral Light | `#F1F5F9` | Light backgrounds (light mode only) |
| White | `#FFFFFF` | Text on dark backgrounds, card backgrounds |

**Source:** PRD Section 3 (Color Palette), AGENTS.md (Design System)

**Accent reserved for:** Section dividers, hover states, variant swatch borders, form focus rings, success indicators, links.

**CTA reserved for:** "Shop Now", "Add to Cart", "Buy Now", "Subscribe", "Proceed to Checkout" buttons only.
