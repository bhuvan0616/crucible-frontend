## SDK Integration

Orders are fetched via `sdk.store.order.list()` — the SDK attaches the JWT token automatically from `authStore.customer.id`.

**Key interface from MedusaJS SDK (`@medusajs/js-sdk`):**
```typescript
sdk.store.order.list(params?: {
  fields?: string;
  limit?: number;
  offset?: number;
  filters?: Record<string, any>;
})
```

The authenticated customer's orders are returned automatically — no explicit `customer_id` param needed; the JWT token carries it.
