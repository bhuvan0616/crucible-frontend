**Store interface:**
```typescript
interface CartStore {
  cartId: string | null
  items: CartItem[]
  totals: CartTotals
  isLoading: boolean
  isInitialized: boolean
  initCart: () => Promise<void>
  addItem: (variantId: string, quantity: number, customization: string) => Promise<void>
  updateQuantity: (lineItemId: string, quantity: number) => Promise<void>
  removeItem: (lineItemId: string) => Promise<void>
  clearCart: () => Promise<void>
}
```

**initCart action:**
- Check localStorage for `cart_id`
- If cartId exists, call `sdk.store.cart.retrieve(cartId, { fields: "id,*items,*items.variant,*items.variant.product,subtotal,shipping_total,tax_total,total" })` — wrap in try/catch
- If retrieval fails or no cartId, call `sdk.store.cart.create({})`, store ID in localStorage
- Map cart.items to CartItem[] via transformLineItem
- Extract totals via extractTotals
- Set isInitialized: true

**addItem action:**
- Get cartId from state — if null, return early
- Set isLoading: true
- Call `sdk.store.cart.createLineItem(cartId, { variant_id: variantId, quantity, metadata: { customization: customization.slice(0, 12) } })`
- On response: map cart.items via transformLineItem, extract totals
- Always set isLoading: false in finally

**updateQuantity action:**
- Same pattern: call `sdk.store.cart.updateLineItem(cartId, lineItemId, { quantity })`
- Sync state from response

**removeItem action:**
- Call `sdk.store.cart.deleteLineItem(cartId, lineItemId)`
- Sync state from response

**clearCart action:**
- Call `sdk.store.cart.delete(cartId)` or create new cart
- Clear localStorage cart_id, reset state to initial

**Persist config:**
```typescript
{
  name: "crucible-cart",
  storage: createJSONStorage(() => localStorage),
  partialize: (state) => ({ cartId: state.cartId }), // Only persist cartId — Medusa is source of truth for items
}
```

**Keep these selectors:**
- `selectCartItemCount` — sum of items[].quantity
- Remove `selectCartTotal`, `selectCartSubtotal`, `selectShippingCost`, `selectCartTotalWithShipping` — totals come from Medusa now, exposed as `totals` on store state

The key is: NO local uuid generation, NO optimistic updates, server-first sync.
